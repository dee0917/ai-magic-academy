# 咒語品質守門 Rubric（Spell Quality Gate）

> 用途：自動化擴充咒語庫時，每一張上站前的強制關卡。
> 授權：2026-06-02 用戶授權自動研究熱門需求、鍛造、上站，條件是「不重複、不低質、真正解決大眾熱門需求」，且「用戶審查發現的問題要寫進這份 rubric 避免再犯」。
> 這份檔會持續長大：每次用戶挑出問題 → 寫進「糾錯紀錄」→ 之後每張都要過。

---

## 0. 上站前流程（每日自動跑）

1. 研究：抓當下台灣＋全球熱門、大眾真正在煩的問題（來源範例：董氏基金會、諮商心理師公會、Heho、Deloitte Gen Z 調查、OpenAI 使用數據、Dcard/PTT/Threads 熱議）。
2. 查重（HARD GATE 1）：跟現有全部咒語比對「場景＋解決的問題」，只要實質重複就淘汰。
3. 評分（HARD GATE 2）：用下方五維 Rubric 評分，未達門檻不上站。
4. 結構檢查（HARD GATE 3）：符合 spell-forge 規格（modules、generate 五段、禁語、驗證測試）。
5. 融合鏈安全（HARD GATE 4）：不得砍動既有咒語；新咒語預設不接 FUSION_RECIPES（除非刻意設計且不破壞既有配方）。
6. 通過才 build → 部署 → 記錄。
7. 自我節制：品質 > 數量。每次最多 3 張；當天若沒有夠好又不重複的，就不上架（寧缺勿濫）。

---

## 1. 五維評分（每項 1-5，滿分 25）

| 維度 | 說明 |
|------|------|
| 痛點強度 | 問題多痛、多急、多高頻 |
| 不可替代性 | 是否「自己亂打一句 ChatGPT 也能得到」→ 越不可替代越高分（核心） |
| 即用度 | 產出能否直接複製就用 |
| 驚豔感 | 有無重新框架問題、給出想不到的角度 |
| 受眾廣度 | 多少人會遇到 |

**上站門檻：總分 ≥ 16（A 級）才上站。** 12-15（B）退回重寫，<12（C）直接砍。

---

## 2. 查重清單（現有咒語場景，禁止實質重複）

職場：遲到通知、委婉拒絕、一句說服、會議提問防禦、搶功反殺、升遷加薪、高風險談判/離職談判、職場不公追討、幕後多方操盤
人際：拒絕請求、道歉修復、承諾鎖定、口頭協議追索、情緒勒索脫困、優雅拒絕、衝突轉化、心理鐵壁/PUA防禦、有毒關係重生、讀心防壁
日常：尷尬修復、殺價比價、讀空氣、社交出包轉機、戰術脫身
要錢/家庭：跟長輩要錢、合夥防爆、關係憲法
校園：分組報告、教授應對、考前焦慮、校園社交人際地圖
創業：（多由融合涵蓋）
生活娛樂：追劇接續、旅遊行程規劃、下廚料理靈感（冰箱食材→食譜）
> 新咒語的「場景＋解決的問題」不得落在以上任何一格的實質範圍內。

---

## 3. 結構硬規格（缺一不可）

- `id` snake_case 唯一；`title` =「動作詞：問題描述」≤12 字；`desc` 含問題情境＋機制。
- `tags` 恰好 3 個；`fields` 數量符合階級（見習 2-3、中階 3-4、高階 4-5、大魔導 5-6、禁忌 6+）。
- `tweak.options` 格式「特徵型：優勢描述」；`modules` 4-6 個（這是「咒語解析」功能，每張都要有）。
- `theory` 至少引用 1 個心理學/學理框架。
- `generate()` 五段：角色設定 → 採用策略 → 任務+欄位注入 → 輸出規格（編號+字數） → 規則恰好 5 條（①格式 ②禁語列具體詞 ③框架 ④語氣 ⑤驗證測試）。
- 全繁體中文、台灣語境、輸出可直接貼 LINE/IG。

## 5. 已知敏感題處理原則

- 心理健康/低潮/自傷類：定位為「自我對話與情緒急救工具」，不可宣稱取代專業；產出結尾必含「情況嚴重請尋求專業協助」類提醒。
- 法律/醫療類：標註「僅供參考，具體請諮詢專業」。
