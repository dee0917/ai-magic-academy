# 提取咒 (Extraction Prompt)

> 用途:貼到任何 AI 聊天的最後,把剛解決的問題萃取成「咒語藍圖」,再丟回給魔法學院的 Claude 轉成正式咒語。
> 對齊:輸出欄位對應 spell-forge 的 Blueprint Mode 輸入,轉換近乎零手工。
> 版本:v1 (2026-06-01)

---

## 使用方式
1. 在你剛用 AI 解決完某件事的那個對話裡,把下面整段貼到最後送出。
2. 把那個 AI 吐出來的「咒語藍圖」整段複製。
3. 丟給魔法學院的 Claude,說「鍛造這張咒語」。

---

## 咒語本體(複製以下整段)

```
你現在切換成「方法萃取師」。請仔細回顧我們在這段對話裡「實際解決的那件事」,把它萃取成一份可重複使用的方法藍圖。不要客套,直接照下面格式輸出,缺項就寫「無」。

【問題情境】
一句話描述這段對話到底幫我解決了什麼(誰、在什麼情況、想達成什麼)。

【有效方法精華】
條列 3 到 5 點,寫出這次「真正讓它成功」的關鍵做法或步驟。只寫有效的,失敗的繞路不要寫。

【可重複使用的提示詞骨架】
把這次有效的方法,改寫成一段「下次換個對象也能直接用」的提示詞。會變動的地方用雙中括號標記,例如 [[作品名稱]]、[[看到第幾集]]。固定不變的指令照寫。

【變數欄位】
列出上面骨架裡所有 [[ ]] 的變數,每個給:名稱 + 一句說明 + 一個範例。

【可切換風格或模式】
列出 2 到 3 種使用者可能想切換的模式(例如:純回顧不暴雷 / 完整含後續、正式 / 輕鬆)。每個寫成「特徵型:這樣做的好處」。

【期望輸出格式】
描述理想的回答長什麼樣(幾個段落、要不要分點、大概多長、能不能直接用)。

【背後原理】
這個方法為什麼有效?有沒有對應的心理學、學習、或資訊整理原理?一兩句即可。

【常見失敗與禁語】
列出 3 到 5 個「這樣寫就會失敗」的反例或不該出現的字句。

【建議分類與階級】
分類從這幾個選一個最接近的:人際擋箭 / 職場求生 / 日常雜症 / 校園生存 / 創業斜槓 / 生活娛樂(資訊整理、追劇追番、學習)。
階級從這幾個選:見習(簡單日常) / 中階 / 高階 / 大魔導 / 禁忌(極專業稀有)。
各給一個建議值並一句話說明理由。
```
